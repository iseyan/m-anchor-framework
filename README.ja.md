# M-Anchor Framework

[English README](README.md)

## 証拠に基づく区別を、出力・記録・行為の過程で保持するための設計枠組み

**状態：** 公開草案  
**最終更新：** 2026年9月27日  
**開発段階：** 原則の整理、限定された保存条件の数理化、探索的な行動評価  
**主な対象：** AIエージェントの状態管理、構造化出力、要約と引き継ぎ、実行時監査、モデル行動評価

M-Anchorは、AIが評価から出力、記録の引き継ぎ、行為へ進む際に、根拠のない確定や意味のすり替えを防ぐための原則・設計枠組みである。

中心となる規則は次のとおりである。

> **出力や行為を要求されたという理由だけで、証拠が未決のまま残している区別を消してはならない。**

十分な根拠がある結論は、その範囲を明示して述べる。根拠が足りない点は未決として保持する。必要な行為を選んだ後も、行為の選択と事実の確定を区別する。

公開済みの中核原則の改訂候補は、[M-Anchor 中核原則 v0.2-rc1 日本語版](principles/core-principles-v0.2-rc1.ja.md)にある。v0.2はまだ正式採用前であり、[v0.1原典](principles/core-principles.ja.md)を現行の基準文書として保持する。フレームワークv0.2と、準備中の形式ノートv0.4は、別の文書の版番号である。

## 1. 現在の研究対象

M-Anchorは当初、人間に関する推論を対象に、根拠のない動機帰属、人物全体への固定化、支持された判断や必要な安全対応の抑制を避ける原則として整理された。

現在は、その問題をAIシステムの処理過程へ広げている。問うのは、評価段階で保持された区別が、フォームへの入力、要約、構造化出力、永続記録、別のエージェントへの引き継ぎ、行為の実行を通じて、どこまで維持されるかである。

特に、次の違いを確認する。

| 区別するもの | 同一視してはならないもの |
| --- | --- |
| 証拠が支持する評価 | インターフェースが要求する出力値 |
| 受理された証拠とその解釈 | 期限、完了要求、行為上の都合 |
| 主張の出典・承認・保存 | その内容が真であることへの支持 |
| 何を実行できるか | 何を実行してよいか、何を実行すべきか |
| 内部に保持した区別 | 下流の受け手が実際に利用できる区別 |

こうした区別の喪失は、検討する失敗機序である。現行システムでの発生頻度や、AI事故全般への寄与が確立されているとは主張しない。

## 2. 最小の例：未決の評価と二値の提出

ある介入の後で指標が改善したが、同時期に別の変更も行われていたとする。証拠から介入の因果的な寄与を識別できない一方、フォームが次の二つだけを要求する場合がある。

- A：介入が改善を引き起こした。
- B：介入は改善を引き起こしていない。

評価では、候補集合として $\{A\}$、$\{B\}$、$\{A,B\}$ の三状態を区別できる。ここで $\{A,B\}$ はAとBを同時に真と認定することではなく、どちらも除外されていない未決状態を表す。しかし、二種類の提出値だけでは、その三状態をすべて区別して伝えられない。

「Bを選ぶが、証拠によってBが確定したわけではない」と説明しても、Bだけを受け取る下流処理には、その留保は渡らない。

この問題に対し、内部の評価、提出値、提出理由を別に保持し、必要な情報を下流へ渡す設計を検討する。外部への出力を要求されること自体は、内部の候補を削除する根拠にはならない。

ただし、フォームのBが公的な事実断言を意味する場合、内部に未決を残すだけでは、その断言を正当化できない。出力の意味と、許容される提出・照会・例外処理を別に扱う必要がある。

## 3. 維持する中核原則

1. **命題ごとに評価する。** 確立された事実、正当化された推論、推測、不明・未決を区別し、証拠へのアクセスと出典を明示する。
2. **根拠に応じた強さで判断する。** 不明な原因や動機を創作せず、十分に支持された結論を中立的に見せるためだけに弱めない。
3. **評価と出力を分ける。** 要約、承認、提出、引き継ぎだけで支持度や候補集合を変更しない。
4. **更新の根拠を記録する。** 新しい証拠に限らず、過去の証拠の再適用、推論、前提の訂正を明示して更新する。
5. **行為の根拠を別に確認する。** 事実認定、権限、必要性、緊急性、対応の比例性を混同しない。
6. **人物を判断で閉じない。** 行為や限定された傾向についての評価を、全人格、唯一の真の動機、恒久的な本質、人間としての価値へ拡張しない。

「解釈の余白」は、未決の点と更新条件を保持することを意味する。不確実性を増やすことや、架空の別解を並べることではない。未決、証拠の衝突、行為の未許可も、それぞれ異なる意味を持つ。

## 4. 数理化した範囲

準備中の形式ノート *Epistemic State Preservation under Forced-Choice Interfaces in AI Systems* v0.4では、この原則のうち、保持している候補の除去に対する保存条件を扱う。以下はその形式条件の概要であり、公開済みの論文や経験的な検証結果として紹介するものではない。

ランタイムが保持する候補集合を $K_t\subseteq\Omega$、その遷移に適用する証拠記録を $D_t$、与えられた証拠解釈と両立する集合を $M(D_t)$ とする。$K_t$ は運用上の保持集合であり、受理済みの証拠すべてが既に反映されているとは限らない。また、$K_t$ は確率分布や信頼度スコアではなく、その時点で保持されている候補の集合である。

モデル化された世界と仮説空間を固定し、前提撤回や新規候補の導入を扱わない遷移を対象とする。この範囲で、保存制約MECCと候補集合を拡大しない条件を合わせると、次が得られる。

$$
K_t \cap M(D_t) \subseteq K_{t+1} \subseteq K_t.
$$

この条件を守り、$M(\varnothing)=\Omega$ とする場合、その遷移に証拠基底を適用しなければ、

$$
D_t = \varnothing \quad\Longrightarrow\quad K_{t+1} = K_t.
$$

選択する行為は、この保存結果を変えない。証明は初等的であり、内容は、行為選択、候補の保存、証拠の取り込みを分離した点にある。

ここで $D_t=\varnothing$ は「新しい観察が届いていない」という意味ではない。過去に受理した有効な証拠を明示的に再適用すれば、追加の観察がなくても候補を除去できる。

完全な取り込みの基準は $U(K,D)=K\cap M(D)$ である。MECCはそれより弱く、適用した証拠と両立する候補の除去を禁じるだけなので、取り込み不足を別に監視する必要がある。

形式条件は、証拠の真正性、解釈の正しさ、失われた候補の復元、適切な行為、一般的安全性を保証しない。空集合は候補の枯渇を表し、未決や確実性とは区別する。人物固定化や安全対応を含むM-Anchor全体の妥当性が、この定理によって証明されたわけではない。

## 5. 原則・形式条件・実装・評価の関係

| 文書・作業 | 役割 |
| --- | --- |
| 中核原則 | 何を区別し、どのような判断や移行を避けるべきかを定める。 |
| 形式ノート（準備中） | 対象と前提を限定し、候補除去について検査可能な条件を示す。 |
| ランタイムへの指示 | 原則に沿う挙動を促す、実験用の自然言語指示を定める。 |
| 状態管理の実装 | 状態の書き込みと引き継ぎにおいて、条件を実際に守らせる。 |
| 評価記録 | 特定の条件で観察された挙動と、その測定上の限界を記録する。 |

自然言語の指示だけでは、実行時の不変条件は保証されない。また、文章上の未決表現だけでは、永続記録や下流への引き継ぎで候補が残ったことを確認できない。

状態管理を評価する場合は、行為の選択理由に加え、遷移前後の候補、除去された候補、適用した証拠、その解釈を記録する。根拠のない除去、適切な証拠の取り込み、出力要件への適合、下流からの記録の利用可能性を別に確認する。

## 6. 既存の評価記録の読み方

[強制完了下での未決保持に関する技術ノート](reports/non-closure-under-forced-completion.md)には、小規模な指示条件の比較が記録されている。

- FC-01／ZA-01系では、証拠が不十分でも二値を提出した条件と、未決を示して二値の提出を避けた条件の違いが観察された。
- 十分な証拠を与える対照では、試した条件はいずれも判断を確定した。
- 通常の対話、命題の変化、既に承認された記録の扱いに関する試験では、条件間の差が出なかった結果も記録されている。

これらは出力上の挙動差であり、内部の候補集合を計測してMECCへの適合を実証した結果ではない。二値の提出を避けることと、二値を出力しながら内部状態を保存することも、異なる達成条件である。

既存の試験結果を、この区別に合わせて遡及的に採点し直さない。評価上の意味と限界を明示したうえで、原記録を保持する。一般的な優位性、事故防止効果、実環境での発生頻度は未確立である。

## 7. 人間への影響に関する原則

初期版が対象とした、根拠のない意味付け、人物固定化、支持された推論や安全対応の抑制は、引き続き重要な問題である。

重大な危害のおそれがあり、遅延自体が危険となる場合は、最終的な事実認定を待たず、比例的な安全確保の指針を示す。同時に、事実評価と更新を継続する。暫定措置を取ったことを、有罪や原因の確定に読み替えない。

安全措置は状況が許す限り、暫定的、可逆的、非懲罰的、期限付き、見直し可能とする。実行の支援には、機能、同意、権限の確認が必要である。

この安全確保と評価の並行した扱いは、一般的な評価・行為の分離を、人間への影響がある場面で具体化するものである。集合の保存条件とは別の規範的根拠を持つ。
